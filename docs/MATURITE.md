# Le questionnaire de maturité (Maturity & Compliance)

À remplir par Adrien dans le Creator Dashboard (Experience, Audience, Maturity & Compliance Questionnaire) avant la publication. Ce qui suit décrit le jeu tel qu'il est le 7 novembre 2026, pour répondre vrai : le label vient des réponses, et Roblox peut le corriger après coup.

Visé : **Mild**. Un jeu Minimal ou Mild peut être vu par Roblox Kids (5 à 8 ans) et Roblox Select (9 à 15 ans) ; un jeu Moderate par Select et les 16 ans et plus (documentation Roblox, novembre 2026).

## Ce que le jeu contient

| Rubrique | Dans BLIND SPOT | Réponse conseillée |
| --- | --- | --- |
| Violence | L'Invisible « prend » un garde : l'image se fige, la cassette se déchire, le garde se réveille au poste. On ne voit ni coup, ni blessure, ni corps. | Oui, violence **irréaliste** (la conséquence n'est pas montrée), **répétée** (chaque nuit). Donne Mild. |
| Sang | Aucun (CLAUDE.md : « Peur sans gore »). | Non. |
| Peur | C'est un jeu d'horreur : le noir, une silhouette trop grande qui apparaît puis disparaît, la tension, un bruit de cassette déchirée à la prise. Pas d'image horrifiante, pas de gore, pas de cri. | Oui, éléments effrayants **répétés**, pas d'éléments horrifiants. Donne Mild (le palier Moderate est pour les « éléments horrifiants »). |
| Humour grossier | Non. | Non. |
| Romance, alcool, drogues | Non. | Non. |
| Jeux d'argent | Non : aucun objet au hasard, ni payant ni gratuit. | Non. |
| Langage | Aucun juron (relire `content/tapes.csv`, `radio.csv`, `logbook.csv` avant chaque mise à jour). | Non. |
| Achats | Deux produits Robux prévus (VIP, Overtime +25 % de paie), rien de caché, rien au hasard. | Déclarer les achats s'il le demande. |
| Échanges entre joueurs | Le chat Roblox du lobby (par défaut). Pendant un quart, pas de texte : six signaux fixes (`content/signals.csv`). | Selon la question : chat texte oui (celui de Roblox). |

## Points d'attention

- **Les flashs** : jamais plus de 3 par seconde (CLAUDE.md), et l'option Reduce Flashes adoucit les vacillements.
- **Les images générées** (icônes, miniature) : les regarder avant chaque téléversement ; rien de sanglant.
- **Si une mise à jour ajoute** une créature plus horrible, du sang, ou une scène de mort montrée, il faut **refaire le questionnaire** : le label serait faux.
- **Si Roblox classe le jeu Moderate** malgré tout, il reste visible aux 9 à 15 ans par Roblox Select ; pas besoin de changer le jeu dans l'urgence.
