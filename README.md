# BLIND SPOT

Un jeu d'horreur Roblox en première personne, solo ou en coop de 1 à 4, au décor photoréaliste. Tu fais la ronde de nuit dans un bâtiment fermé ; l'Invisible n'existe que là où aucune caméra ne regarde. Reste dans le champ d'une caméra.

Ce dépôt contient le plan et la recherche ; le code viendra ensuite.
